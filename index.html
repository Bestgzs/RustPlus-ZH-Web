01 · 配对服务器

首次使用需要关联自己的 Steam 账号。后台启动或收到新配对后会自动连接。

  1. 点击按钮，在专用浏览器窗口（优先 Chrome，未安装时自动用 Edge）登录 Steam。
  2. 登录成功后，进入 Rust 目标服务器。
  3. 按 ESC → Rust+ → 与服务器配对。
  4. 收到配对通知后会自动保存并连接服务器。
尚未配对

登录由 Rust+ 库提供，专用浏览器窗口（Chrome 或 Edge）会临时关闭跨站隔离以接收配对结果；仅用于 Steam 配对，完成后自动关闭。独立配置保存在本程序的 data 目录。

导入已有配对配置

支持 Rust+ 配置 JSON 或服务器配对通知 JSON。令牌仅保存在本机。

游戏内与 Discord 怎么用

在游戏队伍聊天或Discord 频道发送命令（Discord 同时支持斜杠命令 /time /pop /pos /deaths /map /say /leader）：
!时间 / !time · 当前游戏时间 + 天亮/天黑倒计时
!人数 / !pop · 服务器在线人数与排队人数
!位置 / !pos · 全体队友当前地图网格坐标
!死亡 / !deaths · 本次运行最近死亡记录（含网格坐标）
!队长 / !leader [名字] · 将队长移交给自己或指定队友（需本人当前为队长）
!地图 / !map（仅 Discord）· 发送服务器高清地图与队友坐标到 Discord
!发送 内容 / !say 内容（仅 Discord）· 从 Discord 发消息到游戏队伍频道
!帮助 / !help · 查看命令列表

死亡依据 Rust+ 队伍状态轮询检测，可能存在约 10 秒延迟；离线或断线期间的死亡可能漏报。
