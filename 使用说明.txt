Rust+ 中文队伍助手 1.0.0 — Windows 便携版

系统：Windows 10/11 64 位；Steam 配对登录需要 Google Chrome 或 Microsoft Edge（优先 Chrome，未安装时自动用 Windows 自带的 Edge）。
内含 Node.js 24.19.0 与依赖，无需额外安装 Node.js、Python 或 PowerShell 7。

使用步骤
1. 将压缩包完整解压到可写文件夹。不要在压缩包内直接双击运行。
2. 双击 Start.cmd，网页会自动打开：http://127.0.0.1:3210/
3. 点击「打开 Steam 配对登录」，在 Steam 官方页面登录自己的账号。
4. 登录成功后，进入 Rust 目标服务器，ESC → Rust+ → 与服务器配对。
5. 网页收到服务器信息后会自动保存并连接（之后每次启动后台也会自动重连上次服务器）。
6. 双击 Stop.cmd 退出后台。仅关闭网页不会停止机器人。

功能
- 队友死亡自动中文播报至游戏队伍频道与 Discord（含地图网格坐标，如 Y5）。
- 队友上线 / 离线提醒（可在网页勾选开启游戏队伍频道与 Discord 播报）。
- 服务器实时高清地图：网页直接查看地图、资源点名称、队友实时位置与最近死亡点，支持鼠标悬停查看网格坐标，并可一键发送地图到 Discord。
- 网页端队伍聊天面板：实时同步游戏内队伍聊天，并可在网页直接打字发送到游戏队伍频道。
- Discord 机器人与 Webhook 联动：
  · 方式 A（Webhook）：粘贴频道 Webhook 链接即可单向推送死亡、上下线、队伍聊天与地图图片。
  · 方式 B（Bot Token + 频道 ID）：完整双向 Discord 机器人，自动注册斜杠命令（/time /pop /pos /deaths /map /say /leader），支持 !时间、!人数、!位置、!死亡、!地图、!发送、!队长 等命令，并支持将 Discord 频道聊天直接转发进游戏内队伍频道。
- 多服务器收藏夹：自动保存配对过的多个服务器，支持下拉框一键切换与管理。
- 游戏队伍聊天命令：
  !时间 / !time   查询当前游戏时间与天亮/天黑倒计时
  !人数 / !pop    查询服务器在线人数与排队人数
  !位置 / !pos    查询全体队友当前地图网格坐标
  !死亡 / !deaths 查询本次运行期间最近死亡记录（含坐标）
  !队长 / !leader 将队长移交给自己或指定队友（需本人当前为队长）
  !帮助 / !help   查看命令列表
- 可选每 5 / 10 / 15 / 30 / 60 分钟定时播报游戏时间与昼夜倒计时。

说明
- 这是本机网页控制台，不是公网网站；电脑和后台需要保持运行。
- 服务只监听 127.0.0.1:3210，没有开机自启。
- 需要服务器支持 Rust+，账号已入队，且网络能访问 Rust+、Steam 和推送服务（若启用 Discord 则需能访问 Discord）。
- 死亡约每 10 秒检测；断线期间可能漏报，首次连接不补发历史死亡。
- 上游 Steam 登录使用专用浏览器配置（Chrome 或 Edge）并临时关闭跨站隔离以接收配对结果；仅用于配对，完成后自动关闭。
- 支持导入已有 Rust+ 配置 JSON 或包含 ip、port、playerId、playerToken 的配对 JSON。
- 每个人都必须自行登录配对；此压缩包不包含任何个人账号凭据。

数据与转发
运行后会生成 data 文件夹及 pair-register.cjs。
data 包含账号配对凭据、配置、浏览器资料和日志，不要转发！
给别人使用时，请直接转发收到的原始压缩包，不要重新打包使用后的目录。
